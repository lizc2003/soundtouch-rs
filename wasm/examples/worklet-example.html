🎵 SoundTouch AudioWorklet Demo

⚠️ Note: This example demonstrates real-time audio processing using AudioWorklet. For this to work properly, you need to:
  • Build the WASM module for web target
  • Serve this page over HTTP/HTTPS (not file://)
  • Have the worklet processor script in the same directory
  • Click "Start Processing" - AudioContext requires user interaction due to browser autoplay policy
Ready. Select an audio source and click "Start Processing".
